Block: valeur_chrono

What is it for?

Returns the elapsed time since the last ‘reset the stopwatch to 0’ block.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Choose the unit: (s) for seconds, (ms) for milliseconds.

Put this block in a block that expects a number: show, compare, store in a variable.

Good to know

  • Without a ‘reset the stopwatch to 0’ block, the time is counted from the start of the board.
  • In seconds, the result can be a decimal number (for example 2.5).

Example

The stopwatch starts from 0 at start, then the elapsed time, in seconds, shows every second.
