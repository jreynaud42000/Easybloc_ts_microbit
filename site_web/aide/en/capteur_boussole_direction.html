compass heading (°)

Block: capteur_boussole_direction

What is it for?

Returns the direction the top of the board points to, in degrees: 0 for north, 90 for east, 180 for south, 270 for west.

This block returns a number (to plug into another block, where a number is expected, or into a comparison block = < >).

How to use it?

Hold the board flat for a correct measurement.

Put the ‘calibrate the compass’ block in the ‘on start’ block.

Good to know

  • If the compass has not been calibrated yet, the board first starts the calibration.
  • A magnet, a motor or an iron object near the board distorts the direction.
  • In the simulator, this measurement does not change (it is always 0): try the program on the real board.

Example

The compass is calibrated once at start, then the direction shows every second.
