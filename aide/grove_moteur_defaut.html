Bloc : grove_moteur_defaut

À quoi ça sert ?

Renvoie le code de défaut du canal choisi du pilote de moteurs Grove : 0 si tout va bien.

Ce bloc renvoie un nombre (à brancher dans un autre bloc, là où on attend un nombre, ou dans un bloc de comparaison = < >).

Comment l'utiliser ?

Comparez le résultat à 0 dans un bloc « si » pour détecter un problème (moteur bloqué, surcharge…).

À savoir

  • Un autre nombre que 0 signale un défaut : utilisez alors le bloc « effacer le défaut sur le moteur canal … ».
  • Le pilote de moteurs Grove (DRV8830) se branche sur un port I2C et commande deux moteurs, sur les canaux 1 et 2.

Exemple

Le code de défaut du canal 1 s'affiche chaque seconde sur la matrice de LED.
